# cicd-learning

CI/CD zero to advanced: hands-on practice repository.

## Structure

- src/ : application code
- tests/ : automated tests
- docs/ : notes
- .github/workflows/ : GitHub Actions pipelines

## Rules

1. main branch mein seedha push nahi. Hamesha branch + Pull Request.
2. Secrets kabhi commit nahi karne.
3. Commit message clear likho (feat:, fix:, chore:, docs:).
